ANEXO II CONFIGURAÇÕES DO SISTEMA
Instalação do Sistema Declaração sobre Operações Imobiliárias Equipamento Necessário: Pentium 100 Mhz com 16 MB de memória RAM ou superior. O 386, 486 com 8 MB de memória apresentará um desempenho lento, prejudicando a performance. Unidade de disco de 3,5" HD. Impressora jato de tinta ou laser. Espaço físico mínimo de 10 Mb Software Necessário: Windows 3.1 ou superior. Instalação do Disquete-Programa No Windows 1- Insira o disquete 1/3 na unidade de disco A ou B; 2 - Escolha Executar no menu Arquivo do Gerenciador de Programas do Windows, para executar o arquivo INSTALAR.EXE. Nota: No Windows 95, clique no botão Iniciar da barra de tarefas e, em seguida, no Executar,digite A:\INSTALAR.EXE ou :\INSTALAR.EXE. Atenção: Antes de iniciar o preenchimento, verifique, em suas configurações Regionais, o símbolo separador para decimal que deverá ser "," (vírgula) e o estilo de data abreviada que deve ser "dd/mm/aaaa" ou "dd/mm/yyyy" (se seu sistema operacional for em inglês). Após a instalação, o software deve ser utilizado por somente um Cartório. Caso haja necessidade de utilização do produto por mais de um Cartório no mesmo micro, o software deve ser instalado novamente, informando durante o processo de instalação, uma pasta (ou diretório) diferente. Desta forma, existirão dois bancos de dados, um para cada Cartório. Deverão ser criados, por sua vez, dois ícones ou atalhos apontando para cada programa instalado.
