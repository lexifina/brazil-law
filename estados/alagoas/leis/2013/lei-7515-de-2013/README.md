# Lei nº 7.515, de 17 de julho de 2013, do Estado de Alagoas

INSTITUI O SELO EMPRESA AMIGA DO IDOSO PARA PESSOAS JURÍDICAS, E O TÍTULO DE AMIGO DO IDOSO PARA PESSOAS FÍSICAS, NO ESTADO DE ALAGOAS.
