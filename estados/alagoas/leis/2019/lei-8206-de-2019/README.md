# Lei nº 8.206, de 3 de dezembro de 2019, do Estado de Alagoas

MENSAGEM Nº 59/2019, REFERENTE AO PROJETO DE LEI QUE AUTORIZA O PODER EXECUTIVO A ABRIR, AO ORÇAMENTO VIGENTE, CRÉDITO SUPLEMENTAR EM FAVOR DO TRIBUNAL DE JUSTIÇA DO ESTADO DE ALAGOAS, NO VALOR QUE MENCIONA, E DÁ OUTRAS PROVIDÊNCIAS.
