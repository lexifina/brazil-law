# Lei nº 8.134, de 7 de agosto de 2019, do Estado de Alagoas

AUTORIZA O PODER EXECUTIVO A PROMOVER A DOAÇÃO ONEROSA DA ÁREA QUE MENCIONA, NO MUNICÍPIO DE BATALHA/AL, PARA FINS DE CONSTRUÇÃO DE UNIDADE ESCOLAR DO INSTITUTO FEDERAL DE ALAGOAS - IFAL, E DÁ OUTRAS PROVIDÊNCIAS.
