# Lei nº 8.109, de 7 de maio de 2019, do Estado de Alagoas

CONSIDERA BEM CULTURAL DO ESTADO DE ALAGOAS, PARA FINS DE TOMBAMENTO DE NATUREZA IMATERIAL A FEIRINHA DE ARTESANATO, QUE FUNCIONA NA ORLA DA PRAIA DE PAJUÇARA NO MUNICÍPIO DE MACEIÓ/AL.
