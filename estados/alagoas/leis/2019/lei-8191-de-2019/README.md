# Lei nº 8.191, de 13 de novembro de 2019, do Estado de Alagoas

FICA ASSEGURADO ÀS PESSOAS COM DEFICIÊNCIA VISUAL O DIREITO DE RECEBER AS CERTIDÕES DE REGISTRO CIVIL CONFECCIONADAS NO SISTEMA DE LEITURA BRAILLE.
