# Lei nº 8.196, de 21 de novembro de 2019, do Estado de Alagoas

MENSAGEM Nº 22/2019, REFERENTE AO PROJETO DE LEI QUE RATIFICA O PROTOCOLO DE INTENÇÕES FIRMADO ENTRE OS ESTADOS DA BAHIA, MARANHÃO, PERNAMBUCO, CEARÁ, PARAÍBA, PIAUÍ, RIO GRANDE DO NORTE, ALAGOAS E SERGIPE, PARA A CONSTITUIÇÃO DO CONSÓRCIO  INTERESTADUAL  COM O OBJETIVO DE PROMOVER O DESENVOLVIMENTO SUSTENTÁVEL NA REGIÃO NORDESTE.
