# Lei nº 8.210, de 5 de dezembro de 2019, do Estado de Alagoas

INSTITUI A POLÍTICA ESTADUAL DE PREVENÇÃO ÀS LESÕES POR ESFORÇOS REPETITIVOS LER OU DISTÚRBIOS OSTEOMUSCULARES RELACIONADOS AO TRABALHO DORT EM ÂMBITO PÚBLICO.
