# Lei nº 7.585, de 11 de março de 2014, do Estado de Alagoas

AUTORIZA O ESTADO DE ALAGOAS A PROMOVER A ALIENAÇÃO DE IMÓVEIS A PARTICULARES EM DECORRÊNCIA DA CONCESSÃO DE INCENTIVOS GOVERNAMENTAIS DO PRODESIN.
