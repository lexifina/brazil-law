# Lei nº 7.610, de 15 de abril de 2014, do Estado de Alagoas

AUTORIZA O PODER EXECUTIVO ABRIR AO ORÇAMENTO VIGENTE CRÉDITO SUPLEMENTAR EM FAVOR DO TRIBUNAL DE JUSTIÇA, E ADOTA OUTRAS PROVIDÊNCIAS.
