# Lei nº 9.101, de 14 de dezembro de 2023, do Estado de Alagoas

RECONHECE COMO PATRIMÔNIO CULTURAL DE NATUREZA IMATERIAL DO ESTADO DE ALAGOAS, A CAVALGADA DE NOSSA SENHORA DO BOM CONSELHO E DÁ OUTRAS PROVIDÊNCIAS.
