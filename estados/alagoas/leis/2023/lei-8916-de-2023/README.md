# Lei nº 8.916, de 24 de julho de 2023, do Estado de Alagoas

AUTORIZA O PODER EXECUTIVO A CELEBRAR PARCERIAS COM AS EMPRESAS JUNIORES DO ESTADO DE ALAGOAS PARA PRESTAR ATIVIDADES DE CONSULTORIA E ASSESSORIA A EMPRESÁRIOS E EMPREENDEDORES.
