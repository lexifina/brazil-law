# Lei nº 9.067, de 13 de dezembro de 2023, do Estado de Alagoas

AUTORIZA O ESTADO DE ALAGOAS A ALIENAR ONEROSAMENTE OS IMÓVEIS A QUE FAZ REFERÊNCIA, E DÁ OUTRAS PROVIDÊNCIAS.
