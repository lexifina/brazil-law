# Lei nº 8.962, de 14 de setembro de 2023, do Estado de Alagoas

AUTORIZA O GOVERNO DO ESTADO A CRIAR O PROGRAMA DE CIRURGIA REPARADORA DE FISSURA LÁBIO-PALATINA NA REDE PÚBLICA DE SAÚDE DO ESTADO DE ALAGOAS E DÁ OUTRAS PROVIDÊNCIAS.
