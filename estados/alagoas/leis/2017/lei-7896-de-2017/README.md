# Lei nº 7.896, de 23 de junho de 2017, do Estado de Alagoas

AUTORIZA O PODER EXECUTIVO A ABRIR, AO ORÇAMENTO VIGENTE, CRÉDITO SUPLEMENTAR EM FAVOR DO FUNDO DE MODERNIZAÇÃO DO PODER JUDICIÁRIO - FUNJURIS, NO VALOR QUE MENCIONA, E DÁ OUTRAS PROVIDENCIAS
