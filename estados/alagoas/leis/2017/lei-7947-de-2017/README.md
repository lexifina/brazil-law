# Lei nº 7.947, de 27 de novembro de 2017, do Estado de Alagoas

ALTERA O ANEXO III, DA LEI ESTADUAL Nº 7.185, DE 28 DE JULHO DE 2010, CRIA O 2º CARGO DE PROVIMENTO EM COMISSÃO DE ASSESSOR DE JUIZ PARA TODAS AS UNIDADES JUDICIÁRIAS DE 1º GRAU DE JURISDIÇÃO, DEFINE ATRIBUIÇÕES DO CARGO E ADOTA PROVIDÊNCIAS CORRELATAS.
