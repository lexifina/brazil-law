# Lei nº 7.898, de 23 de junho de 2017, do Estado de Alagoas

AUTORIZA O PODER EXECUTIVO A ABRIR, AO ORÇAMENTO  VIGENTE, CRÉDITO SUPLEMENTAR EM FAVOR DO TRIBUNAL DE JUSTIÇA DO ESTADO DE ALAGOAS, NO VALOR QUE MENCIONA, E DÁ OUTRAS PROVIDÊNCIAS.

Fonte: Assembleia Legislativa (sapl.al.al.leg.br), <https://sapl.al.al.leg.br/norma/1328>; texto: <http://sapl.al.al.leg.br/media/sapl/public/normajuridica/2017/1328/1328_texto_integral.pdf>
