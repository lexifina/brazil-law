# Lei nº 7.953, de 19 de dezembro de 2017, do Estado de Alagoas

INSTITUI NO CALENDÁRIO DE EVENTOS DO ESTADO DE ALAGOAS, O DIA ESTADUAL PARA A REVITALIZAÇÃO DO RIO SÃO FRANCISCO, E DÁ OUTRAS PROVIDÊNCIAS.
