# Lei nº 7.901, de 23 de junho de 2017, do Estado de Alagoas

AUTORIZA O PODER EXECUTIVO A ABRIR, AO ORÇAMENTO VIGENTE, CRÉDITO SUPLEMENTAR EM FAVOR DO MINISTÉRIO PÚBLICO DO ESTADO DE ALAGOAS - MPE/AL, NO VALOR QUE MENCIONA, E DÁ OUTRAS PROVIDÊNCIAS. ( MENSAGEM Nº 20/2017 )
