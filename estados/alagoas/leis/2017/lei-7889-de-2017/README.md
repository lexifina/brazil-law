# Lei nº 7.889, de 16 de junho de 2017, do Estado de Alagoas

QUE DISPÕE SOBRE A REESTRUTURAÇÃO DAS CARREIRAS DOS SERVIDORES DO PODER JUDICIÁRIO DO ESTADO DE ALAGOAS, REVOGA A LEI ESTADUAL Nº 7.210, 22 DE DEZEMBRO DE 2010, E ADOTA PROVIDÊNCIAS CORRELATAS.
