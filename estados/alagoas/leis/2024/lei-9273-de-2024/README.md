# Lei nº 9.273, de 10 de junho de 2024, do Estado de Alagoas

AUTORIZA O PODER EXECUTIVO A TRANSFERIR  RECURSOS  PROVENIENTES DO DEPARTAMENTO ESTADUAL DE TRÂNSITO  DE ALAGOAS  - DETRAN/AL, PARA O INSTITUTO DE INOVAÇÃO PARA O DESENVOLVIMENTO RURAL SUSTENTÁVEL - EMATER, NO VALOR QUE MENCIONA, E DÁ OUTRAS PROVIDÊNCIAS."
