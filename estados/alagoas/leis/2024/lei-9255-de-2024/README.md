# Lei nº 9.255, de 28 de maio de 2024, do Estado de Alagoas

DISPÕE SOBRE O ESTABELECIMENTO DE PARCERIAS COM TATUADORES PARA ATENDIMENTO DAS MULHERES VÍTIMAS DE VIOLÊNCIA QUE SOFREREM TRAUMAS, QUEIMADURAS E DIFERENTES OCORRÊNCIAS, QUE RESULTARAM EM  MARCAS E  CICATRIZES NA PELE.
