# Lei nº 6.181, de 9 de agosto de 2000, do Estado de Alagoas

AUTORIZA A ABERTURA DE CRÉDITO SUPLEMENTAR NO VALOR DE R$ 4.490.000,00 PARA FINS QUE ESPECIFICA E ADOTA PROVIDÊNCIAS CORRELATAS.
