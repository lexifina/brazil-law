# Lei nº 8.040, de 6 de setembro de 2018, do Estado de Alagoas

INSTITUI NORMA PARA INSTALAÇÃO E FUNCIONAMENTO DE ESTABELECIMENTOS QUE EXECUTAM PROCEDIMENTOS INERENTES A PRÁTICA DE TATUAGEM E BODYPIERCING E DÁ OUTRAS PROVIDENCIAS.
