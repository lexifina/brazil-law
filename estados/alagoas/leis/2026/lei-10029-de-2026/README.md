# Lei nº 10.029, de 25 de agosto de 2026, do Estado de Alagoas

AUTORIZA O PODER EXECUTIVO DO ESTADO DE ALAGOAS A CRIAR O PROGRAMA ESTADUAL "SISTEMINHA ALAGOANO DE PRODUÇÃO SUSTENTÁVEL" COM BASE NO MODELO DESENVOLVIDO PELA EMBRAPA, E DÁ OUTRAS PROVIDÊNCIAS.
