# Lei nº 10.084, de 21 de outubro de 2026, do Estado de Alagoas

INSTITUI O FUNDO ESTADUAL PARA MEDICAMENTOS ESPECIAIS (FEME) NO ESTADO DE ALAGOAS, DESTINADO Á AQUISIÇÃO E DISTRIBUIÇÃO DE MEDICAMENTOS DE ALTO CUSTO E TRATAMENTOS ESPECIAIS NO ÂMBITO DO SISTEMA ÚNICO DE SAÚDE (SUS).
