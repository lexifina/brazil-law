# Lei nº 7.692, de 8 de abril de 2015, do Estado de Alagoas

ESTABELECE A PROIBIÇÃO, EM REUNIÕES PÚBLICAS PARA MANIFESTAÇÕES DE PENSAMENTO, DO USO DE MÁSCARA OU QUALQUER OUTRA FORMA QUE VISE OCULTAR O ROSTO DO CIDADÃO, COM O PROPÓSITO DE IMPEDIR-LHE A IDENTIFICAÇÃO.

Fonte: Assembleia Legislativa (sapl.al.al.leg.br), <https://sapl.al.al.leg.br/norma/84>; texto: <http://sapl.al.al.leg.br/media/sapl/public/normajuridica/2015/84/84_texto_integral.pdf>
