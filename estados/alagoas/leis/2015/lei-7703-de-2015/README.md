# Lei nº 7.703, de 28 de julho de 2015, do Estado de Alagoas

FIXA O PERCENTUAL DA DATA-BASE ACUMULADO DO ANO DE 2014 A SER  APLICADO AOS SUBSÍDIOS DOS SERVIDORES COMISSIONADOS DO PODER JUDICIÁRIO DE ALAGOAS, E DÁ OUTRAS PROVIDÊNCIAS.
