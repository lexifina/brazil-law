# Lei nº 3.789, de 15 de dezembro de 1965, do Estado de Minas Gerais

AUTORIZA O PODER EXECUTIVO A REALIZAR DESPESA ATÉ O LIMITE DE
CR$30.000.000, PARA INSTALAÇÃO DO GINÁSIO INDUSTRIAL DE TEÓFILO OTONI.
