# Lei nº 3.572, de 16 de novembro de 1965, do Estado de Minas Gerais

AUTORIZA O GOVERNO DO ESTADO A CONSTRUIR UM JARDIM DE INFÂNCIA EM CADA
UMA DAS CIDADES QUE ENUMERA.
