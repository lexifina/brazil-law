# Lei nº 3.666, de 3 de dezembro de 1965, do Estado de Minas Gerais

AUTORIZA O PODER EXECUTIVO A CONCEDER À SANTA CASA DE MISERICÓRDIA DE
BELO HORIZONTE, UM AUXÍLIO FINANCEIRO ESPECIAL DE CR$ 50.000.000
(CINQÜENTA MILHÕES DE CRUZEIROS).
