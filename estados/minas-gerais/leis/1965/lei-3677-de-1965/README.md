# Lei nº 3.677, de 6 de dezembro de 1965, do Estado de Minas Gerais

AUTORIZA A ENCAMPAÇÃO DAS ESTRADAS DE RODAGEM QUE INTERLIGAM OS
MUNICÍPIOS DE BICAS, GUARARÁ, PEQUERI, MAR DE ESPANHA, MATIAS BARBOSA,
SIMÃO PEREIRA E SANTANA DO DESERTO.
