# Lei nº 3.834, de 16 de dezembro de 1965, do Estado de Minas Gerais

AUTORIZA O GOVERNO DO ESTADO A CRIAR O QUINTO GRUPO ESCOLAR NA CIDADE
DE JANAÚBA, COM A DENOMINAÇÃO DE ANTÔNIO CATULÉ.
