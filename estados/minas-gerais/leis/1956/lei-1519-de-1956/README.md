# Lei nº 1.519, de 29 de dezembro de 1956, do Estado de Minas Gerais

AUTORIZA O INSTITUTO DE PREVIDÊNCIA DOS SERVIDORES DO ESTADO A CONCEDER
EMPRÉSTIMO EXTRAORDINÁRIO AOS FUNCIONÁRIOS, ENQUANTO PERDURAR O ATRASO
DE PAGAMENTO.
