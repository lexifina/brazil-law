# Lei nº 2.832, de 23 de março de 1963, do Estado de Minas Gerais

AUTORIZA O PODER EXECUTIVO A CONTRATAR EMPRÉSTIMO COM O BANCO NACIONAL
DO DESENVOLVIMENTO ECONÔMICO, NOS TERMOS QUE MENCIONA.
