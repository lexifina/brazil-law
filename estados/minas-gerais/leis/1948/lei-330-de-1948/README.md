# Lei nº 330, de 24 de dezembro de 1948, do Estado de Minas Gerais

APROVA O TERMO DO ACORDO CELEBRADO ENTRE OS GOVERNOS DA UNIÃO E DO
ESTADO DE MINAS GERAIS, PARA A INSTALAÇÃO, NO MUNICÍPIO DE MACHADO,
DE UMA ESCOLA DE INICIAÇÃO AGRÍCOLA E ABRE CRÉDITO PARA ESTE FIM.
