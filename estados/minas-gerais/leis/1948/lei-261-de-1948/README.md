# Lei nº 261, de 5 de novembro de 1948, do Estado de Minas Gerais

EXTINGUE POSTOS DE HIGIENE ESPECIALIZADOS, CRIA UNIDADES SANITÁRIAS
AMBULANTES, DISPÕE SOBRE O SEU PESSOAL E CONTÉM OUTRAS PROVIDÊNCIAS.
