# Lei nº 167, de 13 de julho de 1948, do Estado de Minas Gerais

AUTORIZA O GOVERNO DO ESTADO A ELEVAR AS ESCOLAS REUNIDAS DA VILA DE
IBITIURA, MUNICÍPIO DE PARREIRAS, À CATEGORIA DE GRUPO ESCOLAR.
