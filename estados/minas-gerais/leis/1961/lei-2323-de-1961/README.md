# Lei nº 2.323, de 7 de janeiro de 1961, do Estado de Minas Gerais

CONCEDE FAVORES FISCAIS ÀS INDÚSTRIAS NOVAS QUE SE INSTALAREM NO
ESTADO, E DÁ OUTRAS PROVIDÊNCIAS.
