# Lei nº 2.577, de 28 de dezembro de 1961, do Estado de Minas Gerais

ISENTA DO IMPOSTO DE TRANSMISSÃO "INTER-VIVOS" AS TRANSAÇÕES
IMOBILIÁRIAS, DESTINADAS À AQUISIÇÃO DE CASA PRÓPRIA, ATÉ O LIMITE DE
CR$1.500.000,00 FEITAS PELOS FUNCIONÁRIOS PÚBLICOS CIVIS E MILITARES DO
ESTADO DE MINAS GERAIS.
