# Lei nº 443, de 7 de outubro de 1949, do Estado de Minas Gerais

AUTORIZA O ESTADO DE MINAS GERAIS A SE OBRIGAR, SOLIDARIAMENTE, COMO
FIADOR, NO CONTRATO DE EMPRÉSTIMO A SER CELEBRADO ENTRE A PREFEITURA
MUNICIPAL DE ITAJUBÁ E A CAIXA ECONÔMICA FEDERAL DO RIO DE JANEIRO,
PARA OS SERVIÇOS DE ABASTECIMENTO D'ÁGUA AQUELA CIDADE.
