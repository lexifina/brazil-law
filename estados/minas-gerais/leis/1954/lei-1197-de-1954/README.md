# Lei nº 1.197, de 24 de dezembro de 1954, do Estado de Minas Gerais

CONCEDE FAVORES ÀS COMPANHIAS, EMPRESAS OU COOPERATIVAS QUE SE
ORGANIZAREM PARA REFLORESTAMENTO NO ESTADO.
