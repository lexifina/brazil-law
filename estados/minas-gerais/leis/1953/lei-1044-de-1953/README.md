# Lei nº 1.044, de 22 de dezembro de 1953, do Estado de Minas Gerais

AUTORIZA O ESTADO DE MINAS GERAIS A PARTICIPAR DE UMA SOCIEDADE DE
ECONOMIA MISTA PARA A EXPLORAÇÃO DO TRÁFEGO FLUVIAL EM TODA A BACIA DO
RIO SÃO FRANCISCO.
