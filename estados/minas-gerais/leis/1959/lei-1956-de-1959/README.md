# Lei nº 1.956, de 19 de agosto de 1959, do Estado de Minas Gerais

AUTORIZA O GOVERNO DO ESTADO A ENCAMPAR A ESTRADA QUE LIGA ABAETÉ A BOM
DESPACHO, PASSANDO PELO MUNICÍPIO DE MARTINHO CAMPOS.
