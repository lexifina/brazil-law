# Lei nº 1.992, de 31 de outubro de 1959, do Estado de Minas Gerais

SUSPENDE DESCONTOS DE SERVIDORES NOS MESES DE NOVEMBRO E DEZEMBRO DE
CADA ANO, E DÁ OUTRAS PROVIDÊNCIAS.
