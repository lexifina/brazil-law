# Lei nº 1.851, de 19 de dezembro de 1958, do Estado de Minas Gerais

AUTORIZA O SERVIÇO SOCIAL DO COMÉRCIO (SESC) A TRANSFERIR ÁREA DE
TERRENO E INSTITUI SERVIDÃO PARA OS FINS QUE MENCIONA.
