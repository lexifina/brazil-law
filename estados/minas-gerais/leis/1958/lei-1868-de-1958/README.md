# Lei nº 1.868, de 30 de dezembro de 1958, do Estado de Minas Gerais

AUTORIZA O GOVERNO DO ESTADO A CONCEDER OS SERVIÇOS TELEFÔNICOS ENTRE
OS MUNICÍPIOS DE ARAGUARI, CASCALHO RICO, ESTRELA DO SUL E MONTE
CARMELO.
