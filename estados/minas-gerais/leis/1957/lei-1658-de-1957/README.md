# Lei nº 1.658, de 1º de outubro de 1957, do Estado de Minas Gerais

AUTORIZA O GOVERNADOR DO ESTADO A SUBSCREVER AÇÕES DAS USINAS
SIDERÚRGICAS DE MINAS GERAIS S.A. (USIMINAS), OU EMPRESA CONGÊNERE,
E DÁ OUTRAS PROVIDÊNCIAS.
