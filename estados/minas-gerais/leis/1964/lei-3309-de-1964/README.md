# Lei nº 3.309, de 16 de dezembro de 1964, do Estado de Minas Gerais

AUTORIZA O PODER EXECUTIVO A CELEBRAR CONVÊNIO COM A PREFEITURA
MUNICIPAL DE UBERLÂNDIA, PARA SOLUCIONAR PROBLEMA DE ABASTECIMENTO DE
ÁGUA.
