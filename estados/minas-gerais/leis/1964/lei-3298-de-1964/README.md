# Lei nº 3.298, de 14 de dezembro de 1964, do Estado de Minas Gerais

TRANSFERE A SEDE DO DISTRITO DE SANTO AGOSTINHO DE MINAS, MUNICÍPIO E
COMARCA DE MANTENA, PARA A LOCALIDADE DE NOVA BELÉM.
