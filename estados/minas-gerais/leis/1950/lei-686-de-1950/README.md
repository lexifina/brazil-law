# Lei nº 686, de 24 de novembro de 1950, do Estado de Minas Gerais

AUTORIZA O PODER EXECUTIVO A REALIZAR TRANSAÇÕES PARA POR TERMO OU
PREVENIR LITÍGIOS CONTRA O ESTADO E ABRE CRÉDITO ESPECIAL.
