# Lei nº 567, de 2 de junho de 1950, do Estado de Minas Gerais

AUTORIZA O PODER EXECUTIVO A REALIZAR TRANSAÇÕES COM TITULARES DE
CONDENAÇÕES JUDICIAIS ILÍQUIDAS IMPOSTAS AO ESTADO E DÁ OUTRAS
PROVIDÊNCIAS.
