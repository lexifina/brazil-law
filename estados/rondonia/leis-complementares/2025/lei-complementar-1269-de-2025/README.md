# Lei Complementar nº 1.269, de 7 de abril de 2025, do Estado de Rondônia

Altera a Lei Complementar nº 1.257, de 29 de novembro de 2024, que dispõe sobre a Carreira dos Servidores do Poder Judiciário do Estado de Rondônia, para criar o auxílio equipamento tecnológico para os Oficiais de Justiça.

Fonte: Assembleia Legislativa (sapl.al.ro.leg.br), <https://sapl.al.ro.leg.br/norma/12546>; texto: <http://sapl.al.ro.leg.br/media/sapl/public/normajuridica/2025/12546/lc1269.pdf>
