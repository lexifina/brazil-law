# Lei Complementar nº 980, de 20 de junho de 2018, do Estado de Rondônia

INSTITUI NO ÂMBITO DO MINISTÉRIO PÚBLICO DO ESTADO DE RONDÔNIA O PROGRAMA DE APOSENTADORIA INCENTIVADA (PAI), DESTINADO AOS SERVIDORES DE SEU QUADRO EFETIVO QUE PREENCHAM OS REQUISITOS PARA A APOSENTADORIA VOLUNTÁRIA E DÁ OUTRAS PROVIDÊNCIAS.

Fonte: Assembleia Legislativa (sapl.al.ro.leg.br), <https://sapl.al.ro.leg.br/norma/8476>; texto: <http://sapl.al.ro.leg.br/media/sapl/public/normajuridica/2018/8476/8476_texto_integral.pdf>
