# Lei nº 2.557, de 23 de setembro de 2011, do Estado de Rondônia

AUTORIZA O PODER EXECUTIVO A TRANSFERIR, MEDIANTE DOAÇÃO, IMÓVEIS PERTENCENTES AO ESTADO DE RONDÔNIA, PARA A PREFEITURA MUNICPAL DE ARIQUEMES.
