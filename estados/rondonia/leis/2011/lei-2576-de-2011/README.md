# Lei nº 2.576, de 10 de outubro de 2011, do Estado de Rondônia

DETERMINA QUE OS ÓRGÃOS ESTADUAIS E AS AUTARQUIAS NÃO PODEM CONTRATAR FUNCIONÁRIOS PARA OS CARGOS ABERTOS EM CONCURSO, ENQUANTO NÃO SE ESGOTAR A LISTA DOS CLASSIFICADOS, DENTRO DO SEU PERÍODO DE VALIDADE.

Fonte: Assembleia Legislativa (sapl.al.ro.leg.br), <https://sapl.al.ro.leg.br/norma/5492>; texto: <http://sapl.al.ro.leg.br/media/sapl/public/normajuridica/2011/5492/5492_texto_integral.pdf>
