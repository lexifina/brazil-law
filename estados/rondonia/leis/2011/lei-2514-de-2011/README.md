AUTORIZA O PODER EXECUTIVO A TRANSFERIR, MEDIANTE DOAÇÃO, IMÓVEL PERTENCENTE AO ESTADO DE RONDÔNIA, PARA O MUNICÍPIO DE JI-PARANÁ.
