# Lei nº 2.197, de 2 de dezembro de 2009, do Estado de Rondônia

AUTORIZA O PODER EXECUTIVO ESTADUAL PROCEDER A CESSÃO DE USO GRATUITO DE ÁREA DE PROPRIEDADE DO ESTADO DE RONDÔNIA PARA O INMETRO.
