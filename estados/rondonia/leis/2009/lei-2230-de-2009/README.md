# Lei nº 2.230, de 28 de dezembro de 2009, do Estado de Rondônia

AUTORIZA O PODER EXECUTIVO A PROCEDER À CONTRATAÇÃO DE PROFISSIONAIS NA ÁREA DA SAÚDE, POR TEMPO DETERMINADO, PARA O HOSPITAL DO PÓLO ESTADUAL DE CACOAL, PARA ATENDER NECESSIDADE TEMPORÁRIA DE EXCEPCIONAL INTERESSE PÚBLICO.
