# Lei nº 2.269, de 24 de março de 2010, do Estado de Rondônia

AUTORIZA O PODER EXECUTIVO A ABRIR CRÉDITOS SUPLEMENTARES, ATÉ O MONTANTE DE R$ 16.461.000,00, PARA ATENDER, EXCLUSIVAMENTE, EMENDAS PARLAMENTARES NO EXERCÍCIO FINANCEIRO DE 2010.
