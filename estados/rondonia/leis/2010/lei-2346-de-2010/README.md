# Lei nº 2.346, de 10 de novembro de 2010, do Estado de Rondônia

AUTORIZA O PODER EXECUTIVO A TRANSFERIR, MEDIANTE DOAÇÃO, IMÓVEIS PERTENCENTES AO ESTADO DE RONDÔNIA, PARA O MUNICÍPIO DE VILHENA.
