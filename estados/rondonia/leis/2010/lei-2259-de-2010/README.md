# Lei nº 2.259, de 3 de março de 2010, do Estado de Rondônia

AUTORIZA O PODER EXECUTIVO A TRANSFERIR, MEDIANTE DOAÇÃO, A EDIFICAÇÃO PERTENCENTE AO ESTADO DE RONDÔNIA, ONDE SE ENCONTRA INSTALADA A CÂMARA MUNICIPAL DE COLORADO D’OESTE.
