# Lei nº 2.256, de 3 de março de 2010, do Estado de Rondônia

AUTORIZA O PODER EXECUTIVO A TRANSFERIR, MEDIANTE DOAÇÃO, A EDIFICAÇÃO DO IMÓVEL PERTENCENTE AO ESTADO DE RONDÔNIA, ONDE SE ENCONTRA ESTABELECIDA A UNIDADE MISTA DE SAÚDE NO MUNICÍPIO DE COLORADO D’OESTE.

Fonte: Assembleia Legislativa (sapl.al.ro.leg.br), <https://sapl.al.ro.leg.br/norma/4915>; texto: <http://sapl.al.ro.leg.br/media/sapl/public/normajuridica/2010/4915/4915_texto_integral.pdf>
