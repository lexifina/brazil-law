# Lei nº 1.757, de 31 de julho de 2007, do Estado de Rondônia

AUTORIZA O PODER EXECUTIVO A ABRIR CRÉDITO ADICIONAL SUPLEMENTAR PARA ATENDER EXCLUSIVAMENTE AS ADEQUAÇÕES DAS EMENDAS PARLAMENTARES DO PRESENTE EXERCÍCIO E DÁ OUTRAS PROVIDÊNCIAS.
