# Lei nº 2.848, de 19 de setembro de 2012, do Estado de Rondônia

AUTORIZA O PODER EXECUTIVO A ABRIR CRÉDITO ADICIONAL POR EXCESSO DE ARRECADAÇÃO ATÉ O MONTANTE DE R$ 2.145.500,00 EM FAVOR DA UNIDADE ORÇAMENTÁRIA: FUNDO ESPECIAL DO CORPO DE BOMBEIROS MILITAR - FUNESBOM.
