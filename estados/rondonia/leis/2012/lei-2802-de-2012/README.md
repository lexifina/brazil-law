# Lei nº 2.802, de 8 de agosto de 2012, do Estado de Rondônia

AUTORIZA O PODER EXECUTIVO A ABRIR CRÉDITO ADICIONAL POR EXCESSO DE ARRECADAÇÃO ATÉ O MONTANTE DE R$ 200.000,00 EM FAVOR DA UNIDADE ORÇAMENTÁRIA: FUNDO PENITENCIÁRIO - FUPEN
