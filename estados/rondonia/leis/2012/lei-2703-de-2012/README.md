# Lei nº 2.703, de 9 de abril de 2012, do Estado de Rondônia

AUTORIZA O PODER EXECUTIVO A DOAR BENS QUE TENHAM SIDO ADQUIRIDOS, PRODUZIDOS E/OU CONSTRUÍDOS ATRAVÉS DE RECURSOS PROVENIENTES DA CELEBRAÇÃO DE CONVÊNIOS.
