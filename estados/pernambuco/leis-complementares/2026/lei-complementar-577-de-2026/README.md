# Lei Complementar nº 577, de 28 de outubro de 2026, do Estado de Pernambuco

Altera a Lei Complementar nº 575, de 1º de setembro de 2026, que institui o Novo Programa Especial de Recuperação de Créditos Tributários - PERC 2026.
