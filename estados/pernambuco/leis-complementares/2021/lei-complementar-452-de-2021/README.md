# Lei Complementar nº 452, de 26 de maio de 2021, do Estado de Pernambuco

Altera a Lei Complementar nº 100, de 21 de novembro de 2007, que dispõe sobre o Código de Organização Judiciária do Estado de Pernambuco, para criar a Vara Única Distrital de Fernando de Noronha.
