# Lei Complementar nº 356, de 20 de abril de 2017, do Estado de Pernambuco

Dispõe sobre a redução no valor de crédito tributário relativo ao ICMS, em operações com incentivos ou benefícios fiscais que especifica.

Fonte: ALEPE Legis, <https://legis.alepe.pe.gov.br/texto.aspx?id=27532&tipo=TEXTOORIGINAL>
