# Lei Complementar nº 37, de 5 de dezembro de 2001, do Estado de Pernambuco

Altera a estrutura remuneratória dos cargos integrantes do Grupo Ocupacional Auditoria do Tesouro Estadual - GOATE, e dá outras providências.

Fonte: ALEPE Legis, <https://legis.alepe.pe.gov.br/texto.aspx?id=2139&tipo=TEXTOORIGINAL>
