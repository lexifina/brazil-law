# Lei nº 6.880, de 20 de junho de 2024, do Estado do Amazonas

Estabelece o sexo biológico como o único critério para definição do gênero de competidores em partidas esportivas oficiais no Estado do Amazonas.

Fonte: Assembleia Legislativa (sapl.al.am.leg.br), <https://sapl.al.am.leg.br/norma/13361>; texto: <http://sapl.al.am.leg.br/media/sapl/public/normajuridica/2024/13361/6880.pdf>
