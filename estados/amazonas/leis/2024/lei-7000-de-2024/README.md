# Lei nº 7.000, de 11 de julho de 2024, do Estado do Amazonas

ALTERA a Lei nº 5.690, de 1º de dezembro de 2021 que ISENTA os Municípios de até 50.000 (cinquenta mil) habitantes de apresentar certidões negativas necessárias para firmar convênios com o Estado do Amazonas.

Fonte: Assembleia Legislativa (sapl.al.am.leg.br), <https://sapl.al.am.leg.br/norma/13345>; texto: <http://sapl.al.am.leg.br/media/sapl/public/normajuridica/2024/13345/7000.pdf>
