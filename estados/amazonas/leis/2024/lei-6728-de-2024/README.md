# Lei nº 6.728, de 5 de janeiro de 2024, do Estado do Amazonas

Dispõe sobre a concessão do Passe Livre no sistema rodoviário e fluvial para os pacientes oncológicos, dentro do sistema de transporte coletivo intermunicipal.
