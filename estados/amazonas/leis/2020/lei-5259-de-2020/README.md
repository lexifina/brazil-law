# Lei nº 5.259, de 21 de setembro de 2020, do Estado do Amazonas

Dispõe sobre a obrigatoriedade dos municípios que receberem recursos financeiros para enfrentamento da pandemia do Covid-19 a prestarem contas na forma que especifica
