# Lei nº 5.103, de 14 de janeiro de 2020, do Estado do Amazonas

PROÍBE SUPERMERCADOS, HIPERMERCADOS E SIMILARES A REALIZAREM A CONFERÊNCIA DOS PRODUTOS ADQUIRIDOS PELO CONSUMIDOR APÓS O PAGAMENTO NO CAIXA.
