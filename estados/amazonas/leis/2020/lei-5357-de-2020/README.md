# Lei nº 5.357, de 29 de dezembro de 2020, do Estado do Amazonas

Dispõe sobre a obrigatoriedade de inserção do link do PROCON, nos sites ou demais meios eletrônicos utilizados para oferta, venda e/ou conclusão de contrato de consumo.

Fonte: Assembleia Legislativa (sapl.al.am.leg.br), <https://sapl.al.am.leg.br/norma/11165>; texto: <http://sapl.al.am.leg.br/media/sapl/public/normajuridica/2020/11165/5357.pdf>
