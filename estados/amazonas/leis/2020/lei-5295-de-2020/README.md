# Lei nº 5.295, de 3 de novembro de 2020, do Estado do Amazonas

Altera a Lei nº 4.605, de 28 de maio de 2018, que “Estabelece normas gerais para a realização de concurso público, pela administração direta, autárquica e fundacional no Estado do Amazonas”.

Fonte: Assembleia Legislativa (sapl.al.am.leg.br), <https://sapl.al.am.leg.br/norma/11079>; texto: <http://sapl.al.am.leg.br/media/sapl/public/normajuridica/2020/11079/5295.pdf>
