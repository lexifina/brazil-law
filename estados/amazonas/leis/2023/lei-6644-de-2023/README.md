# Lei nº 6.644, de 14 de dezembro de 2023, do Estado do Amazonas

AUTORIZA o Poder Executivo Estadual a alienar o imóvel público estadual que especifica, localizado à Rua Maria Azevedo Ramos, Qd. 53, Lote 298, n.º 1195, bairro Redenção, Manaus, Amazonas.
