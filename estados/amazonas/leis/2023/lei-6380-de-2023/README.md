# Lei nº 6.380, de 2 de agosto de 2023, do Estado do Amazonas

Proíbe a pessoa jurídica condenada pela prática do trabalho análogo à escravidão de contratar com a administração pública estadual e dá outras providências.

Fonte: Assembleia Legislativa (sapl.al.am.leg.br), <https://sapl.al.am.leg.br/norma/12598>; texto: <http://sapl.al.am.leg.br/media/sapl/public/normajuridica/2023/12598/6380.pdf>
