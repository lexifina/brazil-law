# Lei nº 6.271, de 3 de julho de 2023, do Estado do Amazonas

MODIFICA dispositivos da Lei n.º 3.430, de 3 de setembro de 2009, que reduz a base de cálculo nas operações internas com querosene de aviação (QAV) e gasolina de aviação (GAV).
