# Lei nº 6.431, de 18 de setembro de 2023, do Estado do Amazonas

Dispõe sobre a proibição de utilização de recursos públicos as entidades de prática desportiva condenadas por manipulação de resultados.

Fonte: Assembleia Legislativa (sapl.al.am.leg.br), <https://sapl.al.am.leg.br/norma/12659>; texto: <http://sapl.al.am.leg.br/media/sapl/public/normajuridica/2023/12659/6431.pdf>
