# Lei nº 6.536, de 25 de outubro de 2023, do Estado do Amazonas

Dispõe sobre a adoção do Sistema de Inclusão Escolar “ABA” para crianças e adolescentes com Transtorno do Espectro Autista (TEA) nas escolas da Rede Pública.
