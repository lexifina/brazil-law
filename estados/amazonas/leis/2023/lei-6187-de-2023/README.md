# Lei nº 6.187, de 3 de janeiro de 2023, do Estado do Amazonas

Assegura, no âmbito do Sistema Estadual de Saúde, os direitos de mulheres que sofram perda gestacional ou neonatal no Estado do Amazonas e dá outras providências.

Fonte: Assembleia Legislativa (sapl.al.am.leg.br), <https://sapl.al.am.leg.br/norma/12343>; texto: <http://sapl.al.am.leg.br/media/sapl/public/normajuridica/2023/12343/6187.pdf>
