# Lei nº 6.542, de 6 de novembro de 2023, do Estado do Amazonas

Autoriza o Poder Executivo a instituir o Programa Auxílio Aluguel no Estado do Amazonas na forma que se especifica, e dá outras providências.

Fonte: Assembleia Legislativa (sapl.al.am.leg.br), <https://sapl.al.am.leg.br/norma/12823>; texto: <http://sapl.al.am.leg.br/media/sapl/public/normajuridica/2023/12823/6542.pdf>
