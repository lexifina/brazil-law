# Lei nº 5.609, de 16 de setembro de 2021, do Estado do Amazonas

INSTITUI O TERCEIRO DOMINGO DE NOVEMBRO COMO O "DIA ESTADUAL EM MEMÓRIA DAS VÍTIMAS DE TRÂNSITO" NO ESTADO DO AMAZONAS, E DÁ OUTRAS PROVIDÊNCIAS.
