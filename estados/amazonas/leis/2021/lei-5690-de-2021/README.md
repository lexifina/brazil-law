# Lei nº 5.690, de 2 de dezembro de 2021, do Estado do Amazonas

ISENTA os Municípios de até 50.000 (cinquenta mil) habitantes de apresentar certidões negativas necessárias para firmar convênios com o Estado do Amazonas.

Fonte: Assembleia Legislativa (sapl.al.am.leg.br), <https://sapl.al.am.leg.br/norma/11651>; texto: <http://sapl.al.am.leg.br/media/sapl/public/normajuridica/2021/11651/5690.pdf>
