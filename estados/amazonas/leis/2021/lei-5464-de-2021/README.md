# Lei nº 5.464, de 14 de maio de 2021, do Estado do Amazonas

DISPÕE SOBRE A INCLUSÃO NO CALENDÁRIO ESCOLAR, COMO ATIVIDADE EXTRACURRICULAR, DE UMA “OFICINA DE PROFISSÕES” PARA ALUNOS DE ESCOLAS ESTADUAIS DO ESTADO DO AMAZONAS E DÁ OUTRAS PROVIDÊNCIAS.
