# Lei nº 5.607, de 16 de setembro de 2021, do Estado do Amazonas

CRIA O SELO “PRODUTO AMAZONENSE” PARA ATESTAR A ORIGEM E INCENTIVAR O CONSUMO DE PRODUTOS HORTIFRUTIGRANJEIROS PRODUZIDOS NO ESTADO.
