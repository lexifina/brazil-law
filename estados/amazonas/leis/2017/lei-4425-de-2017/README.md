# Lei nº 4.425, de 6 de janeiro de 2017, do Estado do Amazonas

DECLARA COMO PATRIMÔNIO CULTURAL DE NATUREZA IMATERIAL DO ESTADO DO AMAZONAS, A RÁDIO DIFUSORA E DÁ OUTRAS PROVIDÊNCIAS.
