# Lei nº 4.777, de 18 de janeiro de 2019, do Estado do Amazonas

OBRIGA OS ESTABELECIMENTOS COMERCIAIS A COLOCAREM OS MONITORES DA CAIXA REGISTRADORA DE FORMA VISÍVEL E SEM OBSTÁCULOS PARA O CONSUMIDOR.
