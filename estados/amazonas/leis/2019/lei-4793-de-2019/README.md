# Lei nº 4.793, de 22 de março de 2019, do Estado do Amazonas

AUTORIZA O ESTADO DO AMAZONAS A DOAR O IMÓVEL QUE ESPECIFICA À PREFEITURA MUNICIPAL DE AUTAZES, DESTINADO À INSTALAÇÃO DE UMA FEIRA COBERTA NA COMUNIDADE MONTE SINAI.
