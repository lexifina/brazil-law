# Lei nº 4.824, de 29 de abril de 2019, do Estado do Amazonas

INSTITUI, NA REDE ESTADUAL DE ENSINO, A SEMANA ESTADUAL DE CONSCIENTIZAÇÃO DO AUTISMO, A SER COMEMORADA, ANUALMENTE, A PARTIR DO DIA 02 DE ABRIL, COMO É COMEMORADO O DIA MUNDIAL DE CONSCIENTIZAÇÃO DO AUTISMO, E DÁ OUTRAS PROVIDÊNCIAS.
