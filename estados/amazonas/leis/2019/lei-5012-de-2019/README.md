DISPÕE SOBRE A PROIBIÇÃO DA COBRANÇA DE VALORES ADICIONAIS, SOBRETAXA PARA MATRÍCULA OU MENSALIDADE DE ESTUDANTES COM SÍNDROME DE DOWN, AUTISMO, TRANSTORNO INVASIVO DO DESENVOLVIMENTO OU OUTRAS SÍNDROMES.
