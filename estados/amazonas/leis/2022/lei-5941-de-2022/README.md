# Lei nº 5.941, de 22 de junho de 2022, do Estado do Amazonas

REVOGA a Lei Promulgada nº 358, de 28 de dezembro de 2016, que “Obriga os estabelecimentos de supermercados informar aos consumidores os caixas disponíveis para atendimento no intuito de evitar filas desnecessárias”.

Fonte: Assembleia Legislativa (sapl.al.am.leg.br), <https://sapl.al.am.leg.br/norma/11984>; texto: <http://sapl.al.am.leg.br/media/sapl/public/normajuridica/2022/11984/5941.pdf>
