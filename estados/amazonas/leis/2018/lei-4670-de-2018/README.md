# Lei nº 4.670, de 26 de outubro de 2018, do Estado do Amazonas

PROÍBE O USO DE GASES INFLAMÁVEIS PARA PREENCHIMENTO DE BALÕES DESTINADOS AO USO RECREATIVO OU DECORATIVO NO ESTADO DO AMAZONAS.
