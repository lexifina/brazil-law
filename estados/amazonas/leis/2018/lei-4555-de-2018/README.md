# Lei nº 4.555, de 23 de fevereiro de 2018, do Estado do Amazonas

DECLARA COMO PATRIMÔNIO CULTURAL DE NATUREZA IMATERIAL DO ESTADO DO AMAZONAS, A BANDA BLUE BIRDS E DÁ OUTRAS PROVIDÊNCIAS.
