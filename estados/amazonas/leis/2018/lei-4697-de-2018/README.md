# Lei nº 4.697, de 29 de novembro de 2018, do Estado do Amazonas

CRIA O PROGRAMA DE FISIOTERAPIA PARA IDOSOS (FISIOTERAPIA GERIÁTRICA) EM TODA REDE PÚBLICA ESTADUAL DE SAÚDE E DÁ OUTRAS PROVIDÊNCIAS.
