# Lei nº 4.844, de 29 de setembro de 2026, do Estado do Acre

Institui o Programa Estadual de Contribuição Ambiental Empresarial - PECAE, estabelece a Política de Incentivo às Ações Ambientais Empresariais e cria o certificado “Reconhecimento de Contribuição Ambiental Empresarial”, no Estado.
