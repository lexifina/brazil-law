# Lei nº 3.506, de 8 de agosto de 2019, do Estado do Acre

Dispõe sobre a obrigatoriedade das empresas prestadoras de serviços, informar aos consumidores previamente, os dados dos funcionários que executarão os serviços demandados em suas residências ou sedes.
