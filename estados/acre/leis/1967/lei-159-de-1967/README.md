# Lei nº 159, de 18 de dezembro de 1967, do Estado do Acre

Dispõe sobre o orçamento de 1967, fixa anulações de dotações orçamentárias, autoriza o Poder Executivo a abrir créditos suplementares e realizar operações de crédito.
