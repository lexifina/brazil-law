# Lei nº 4.337, de 5 de março de 2024, do Estado do Acre

Dispõe sobre autorização para doação de imóveis públicos ao Estado do Acre, para fins de construção de moradias, no âmbito do Programa Minha Casa, Minha Vida - PMCMV.
