# Lei nº 2.020, de 11 de agosto de 2008, do Estado do Acre

Autoriza o Poder Executivo Estadual a doar para a Universidade Federal do Acre os bens patrimoniais do Instituto Estadual de Desenvolvimento da Educação Profissional Dom Moacir Grechi.
