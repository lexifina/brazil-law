# Lei nº 7.257, de 3 de outubro de 2019, do Estado do Piauí

AUTORIZA O PODER EXECUTIVO A ABRIR CRÉDITO ADICIONAL SUPLEMENTAR VINCULADO ÀS DESPESAS DO FUNDO DE PREVIDÊNCIA, DÍVIDA PÚBLICA, PRECATÓRIOS E DÁ OUTRAS PROVIDÊNCIAS.
