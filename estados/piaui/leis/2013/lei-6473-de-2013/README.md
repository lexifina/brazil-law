# Lei nº 6.473, de 23 de dezembro de 2013, do Estado do Piauí

AUTORIZA O PODER EXECUTIVO A DOAR AO MUNICÍPIO DE PIRACURUCA-PI O IMÓVEL QUE ESPECIFICA, E DÁ OUTRAS PROVIDÊNCIAS.
