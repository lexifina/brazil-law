# Lei nº 6.460, de 19 de dezembro de 2013, do Estado do Piauí

AUTORIZA O PODER EXECUTIVO A CONTRATAR OPERAÇÃO DE CRÉDITO JUNTO AO BANCO INTERNACIONAL PARA RECONSTRUÇÃO E DESENVOLVIMENTO (BIRD), PARA FINANCIAMENTO DO PROJETO PIAUÍ: PILARES DE CRESCIMENTO E INCLUSÃO SOCIAL, NA MODALIDADE SWAP - EMPRÉSTIMO DE ABORDAGEM MULTISSETORIAL.

Fonte: Assembleia Legislativa (sapl.al.pi.leg.br), <https://sapl.al.pi.leg.br/norma/870>; texto: <http://sapl.al.pi.leg.br/media/sapl/public/normajuridica/2013/870/870_texto_integral.pdf>
