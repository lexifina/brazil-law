# Lei nº 5.344, de 29 de outubro de 2003, do Estado do Piauí

AUTORIZA O PODER EXECUTIVO A DOAR AO MUNICÍPIO DE WALL FERRAZ O IMÓVEL QUE ESPECÍFICA E DÁ OUTRAS PROVIDÊNCIAS.
