# Lei nº 5.477, de 10 de agosto de 2005, do Estado do Piauí

AUTORIZA O PODER EXECUTIVO A ABRIR CRÉDITO ADICIONAL SUPLEMENTAR NO ORÇAMENTO DO ESTADO, NO VALOR DE R$ 225.012.000,00, PARA OS FINS QUE ESPECIFICA.
