# Lei nº 5.527, de 26 de dezembro de 2005, do Estado do Piauí

AUTORIZA O PODER EXECUTIVO A DOAR AO MUNICÍPIO DE SANTANA DO PIAUÍ O IMÓVEL QUE ESPECIFICA E DÁ OUTRAS PROVIDÊNCIAS.
