# Lei nº 7.838, de 29 de junho de 2022, do Estado do Piauí

"AUTORIZA O PODER EXECUTIVO ESTADUAL A REGULARIZAR A DOAÇÃO DO IMÓVEL PARA O MUNICÍPIO DE LAGOA ALEGRE (PI), SITUADO NO MUNICÍPIO DE LAGOA ALEGRE ONDE FUNCIONOU A ESCOLA MUNICIPAL JOSÉ ARAÚJO COELHO".
